# Day 02 – Data Cleaning with Python and Pandas

## Project Overview
This project focuses on cleaning a customer dataset using Python and Pandas. The goal was to identify and handle missing values and duplicate records to prepare the data for further analysis.

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
- VS Code

## Tasks Performed
1. Created and explored a customer dataset.
2. Inspected dataset structure and statistical summaries.
3. Identified missing values.
4. Detected duplicate records.
5. Removed duplicate rows.
6. Replaced missing customer names with "Unknown".
7. Filled missing ages using the median.
8. Filled missing purchase amounts using the median.
9. Verified the cleaned dataset.
10. Exported the cleaned dataset as a CSV file.

## Final Results
- Original records: 10
- Records after removing duplicates: 9
- Columns: 6
- Missing values after cleaning: 0
- Duplicate records after cleaning: 0

## Project Files
- `Day_02_Data_Cleaning.ipynb` – Notebook containing the data-cleaning process.
- `cleaned_customers.csv` – Final cleaned dataset.

## Key Learning
Learned how to identify missing values, remove duplicate records, apply appropriate missing-value treatment methods, and export cleaned data using Pandas.
