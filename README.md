## Day 02 – Data Cleaning with Python and Pandas

**Objective:** Clean a customer dataset by identifying missing values, handling duplicates, and preparing reliable data for analysis.

**Tools:** Python, Pandas, NumPy, Jupyter Notebook

**Work Completed:**
- Identified missing values.
- Detected and removed duplicate records.
- Filled missing customer names with "Unknown".
- Used median values to fill missing ages and purchase amounts.
- Verified the cleaned dataset.
- Exported the cleaned data to CSV.

**Final Result:**
- Original records: 10
- Cleaned records: 9
- Missing values: 0
- Duplicate records: 0
